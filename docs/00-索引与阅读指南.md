# 模组介绍册 · 索引与阅读指南

- 适用版本：**2.1.1**（Minecraft 26.1 / Fabric / Java 25）
- 本册共 14 个文件：本索引 + 13 章；章内 `§x.y` 是**册内编号**（与规格文档的 § 无关）。
- 写作原则：**每一类只写自己的内容**——机制在机制章讲一次，物品与界面章只写"是什么、怎么用"，细节用 `见 §x.y` 指过去。

## §0.1 三条阅读路径

| 你是 | 按这个顺序读 |
|---|---|
| **第一次玩** | §2 新手入门 → §4 魔法体系 → §5 学习与进阶 |
| **要查某件东西** | §7 物品图鉴 → §8 方块与设施 → §10 界面与操作 |
| **要开服 / 排错** | §11 指令与多人 → §12 存档与排错 |
