# §7 物品图鉴

本章收齐 24 件物品，按用途分四组：净化系 6 件、魔法系 7 件、证书与申请书 5 件、载体与容器 6 件。每条只写身份、获取、一句话用途与能确认的数值；机制细节用「见 §x」指到对应章节。

净化魔法球、净化法阵、净化魔法阵是实体而不是物品，不列在这里，归 §3 净化体系。

## §7.1 净化系物品

### 净化水晶

- 名称 / ID：净化水晶（Equipoise Crystal，`equipoise_crystal`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：长按右键持续获得一组增益，脚下同时出现一块跟着你走的净化法阵。
- 关键数值：面板伤害 10、攻速 -2.4；增益持续 60 秒（松手后走完剩余时间）；法阵边长 2 格；火焰免疫、不可破坏。
- 详见：见 §3 净化体系

### 净化法杖

- 名称 / ID：净化法杖（Equipoise Staff，`equipoise_staff`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：右键施法；按 i 键（综合设置按键）在 15 种模式里选一种——点式、单发线式、持续线式、普通防御魔法阵，外加单体治愈、群体治愈、群体伤害三种魔法阵，以及点火、融化、冻结、制冰、召雷、生水、前方闪光、指向闪光这 8 项技能。
- 关键数值：点式 50 伤害、充能 75 伤害并带小范围爆炸；单发线式 65；持续线式每刻 10；群体伤害阵每秒 15~50；防御阵直径 3 格。
- 详见：见 §3 净化体系

### 净化圣剑

- 名称 / ID：净化圣剑（Equipoise Sword，`equipoise_sword`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：高伤害近战武器，带横扫。
- 关键数值：面板伤害 2000、攻速 2.0；火焰免疫、不可破坏。
- 详见：见 §3 净化体系

### 净化圣弓

- 名称 / ID：净化圣弓（Equipoise Bow，`equipoise_bow`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：套用原版弓，但不需要背包里有箭就能发射。
- 关键数值：耐久 384；可附魔；三张拉弓状态贴图；火焰免疫、不可破坏。
- 详见：见 §3 净化体系

### 归零

- 名称 / ID：归零（Zero Reset，`zero_reset`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：右键发射归零变体的净化魔法球，命中方块会把方块打破。
- 关键数值：命中实体 2000 伤害；长按每 2 tick 连发；弹速 4.5 格/tick；飞行超过 1024 格消失。
- 详见：见 §3 净化体系

### 净化光环

- 名称 / ID：净化光环（Equipoise Halo，`equipoise_halo`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：头盔位护甲，头戴平面模型显示；右键自动穿戴或与头盔交换。
- 关键数值：+20 护甲、+20 盔甲韧性、+80% 击退抗性；自带附魔：水下速掘 I、水下呼吸 X、保护 / 爆炸保护 / 火焰保护 / 弹射物保护各 50；火焰免疫、不可破坏。
- 详见：见 §3 净化体系

## §7.2 魔法系物品

### 普通魔法杖

- 名称 / ID：普通魔法杖（Magic Staff，`magic_staff`）
- 获取：在魔法附加台合成——2 个木棍 + 1 个普通魔法水晶 + 1 张魔法学习证
- 用途：按 i 键选已附加的魔法类型 / 模式 / 技能，右键施法；**刚合成时已默认选中点式**（闪光证为第一个技能），可直接右键。
- 关键数值：只能附加七种自然魔法，不能附加起源魔法；合成消耗 30 点魔力值；产物与放入的那张学习证编号绑定。
- 详见：见 §4 魔法体系

### 普通魔法水晶

- 名称 / ID：普通魔法水晶（Magic Crystal，`magic_crystal`）
- 获取：在魔法聚合台合成，一次 5 秒；此外击杀没有生命的魔法体 10%、考试里的试炼体 30% 各掉 1 个（不吃抢夺；考试中自动进奖励箱）
- 用途：带在背包或物品栏里，在设置里开启供能后为施法顶上魔力。**也是水晶块的产物与水晶拆合台的材料**——水晶块掉落 4~9 个，8 个可在拆合台合成 1 块、1 块可拆回 8 个（见 §8.7、§8.8）。
- 关键数值：容量 30000；维持存在值 800，低于它立即消失并释放剩余魔力；合成消耗 30000 点魔力值。
- 详见：见 §6 魔力值

### 永恒水晶

- 名称 / ID：永恒水晶（Eternal Crystal，`eternal_crystal`）
- 获取：仅创造模式或指令；无配方，也不在奖励箱里
- 用途：带在身上时，施法完全不计算魔力值消耗。
- 关键数值：没有容量与消耗；方块功能的消耗不免除。
- 详见：见 §6 魔力值

### 水晶块

- 名称 / ID：水晶块（Crystal Block，`crystal_block`）
- 获取：没有原版合成配方；可在水晶拆合台用 8 个普通魔法水晶合成（见 §8.8），也可从创造分类「沐玖萱」或指令拿；主世界**地下**会自然生成（见 §8.7）
- 用途：在水晶拆合台里拆成 8 个普通魔法水晶；也可以直接当方块摆着用。
- 关键数值：硬度 1.5、抗爆 6.0，挖掘速度同原石；任何材质的镐都能挖，空手挖不下；掉落 4~9 个**普通魔法水晶**（均匀随机），不吃时运、不吃精准采集，也不掉方块本体；六面同贴图、无朝向；音效组同原版紫水晶。
- 详见：见 §8 方块与设施、§7.2「普通魔法水晶」

### 水晶拆合台

- 名称 / ID：水晶拆合台（Crystal Splitter，`crystal_table`）
- 获取：**1 个魔法聚合台 + 1 把钻石镐**，无序合成，**2×2 背包合成区就能做**（生存可造，钻石镐被消耗）；拿到聚合台后配方书里会出现；也可从创造分类「沐玖萱」或指令拿
- 用途：右键打开 9 格拆合界面：拆分模式把 1 个水晶块拆成 8 个普通魔法水晶，合成模式把 8 个普通魔法水晶合成 1 个水晶块。
- 关键数值：水平四朝向；正确工具（斧类，与四个魔法方块同一套判定）挖才掉落自身；界面中心 1 格 + 周围 8 格；左上两个互斥按键「拆分」「合成」；预览格不存放物品，取出才结算。
- 详见：见 §8 方块与设施、§10 界面与操作

### 魔力值探测器

- 名称 / ID：魔力值探测器（Mana Detector，`mana_detector`）
- 获取：仅创造模式或指令；无法合成
- 用途：右键查看以你所在区块为中心的 5×5 区块魔力值。
- 关键数值：一次显示 25 个区块；每次探测 3 秒；界面里可再按「探测」重测，下次打开等于重新探测。
- 详见：见 §6 魔力值

### 生命迁移石

- 名称 / ID：生命迁移石（Life Migration Stone，`life_migration_stone`）
- 获取：原版结构奖励箱 5%（每箱最多 1 个）；创造分类或指令
- 用途：右键打开角色切换界面，在「默认」与「有生命的魔法体」之间转换并消耗。
- 关键数值：不能转换为特殊角色（如 icefair）。
- 详见：见 §9 生物与角色

## §7.3 证书与申请书

### 魔法学习证

- 名称 / ID：魔法学习证（Magic Study Certificate，`magic_study_certificate`）
- 获取：在魔法学习讲台按「申请学习证」产出；编号从 0001 起
- 用途：记录你学过的类型 / 模式 / 技能与等级，并用来给魔法杖附加能力。
- 关键数值：创造模式直接拿到的没有编号，无法使用；一张证可以给无限多把法杖附加；标签只显示编号与类型。
- 详见：见 §5 学习与进阶

### 初学魔法考试申请书

- 名称 / ID：初学魔法考试申请书（Beginner Magic Exam Application，`beginner_magic_exam_application`）
- 获取：讲台「考试或试炼」选 I 级后产出
- 用途：右键开启初学魔法考试，并在右键处生成存放奖励的箱子。
- 关键数值：用一次就消耗，无论是否通过；通过后箱里给魔法熟练证明。
- 详见：见 §5 学习与进阶

### 魔法熟练证明

- 名称 / ID：魔法熟练证明（Magic Proficiency Certificate，`magic_proficiency_certificate`）
- 获取：通过初学魔法考试后，在奖励箱里取得
- 用途：放进讲台②格，把对应模式升到 I 级并消耗。
- 关键数值：绑定魔法类型 + 模式，不绑定学习证编号；只能升到 I 级；标签写「升到 I 级」与绑定内容。
- 详见：见 §5 学习与进阶

### 魔法试炼申请书

- 名称 / ID：魔法试炼申请书（Magic Trial Application，`magic_trial_application`）
- 获取：讲台「考试或试炼」选 II~V 级后产出
- 用途：右键开启魔法试炼，并在右键处生成存放奖励的箱子。
- 关键数值：可直接申请 II~V 里任意一级，不必先有 I 级；用一次就消耗。
- 详见：见 §5 学习与进阶

### 魔法试炼晋级认证

- 名称 / ID：魔法试炼晋级认证（Magic Trial Promotion Certificate，`magic_trial_promotion_certificate`）
- 获取：通过魔法试炼后，在奖励箱里取得
- 用途：放进讲台②格，把对应模式升到认证上写的等级。
- 关键数值：绑定魔法类型 + 模式 + 目标等级；认证等级不高于当前等级时被拒绝；标签会写出目标等级与绑定内容。
- 详见：见 §5 学习与进阶

## §7.4 载体与容器

这一节收的是不直接打架的随身物：背包、书册和两枚令牌。

### 百杉包

- 名称 / ID：百杉包（Baishan Bag，`baishan_bag`）
- 获取：工作台合成（线—地毯—线 / 地毯—箱子—地毯 / 线—地毯—线）；创造分类也有
- 用途：右键打开一个 54 格的大箱子式背包。
- 关键数值：54 格；内容随物品保存，不会丢。
- 详见：见 §10 界面与操作

### 柃之册

- 名称 / ID：柃之册（Book of Ling，`book_of_ling`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：右键打开功能选择界面，进角色切换与玩家尺寸属性。
- 关键数值：身高可输入 4 位（cm），应用后按比例联动移动速度、跳跃强度、生命值、攻击伤害与交互距离等。
- 详见：见 §9 生物与角色

### 魔法书

- 名称 / ID：魔法书（Magic Book，`magic_book`）
- 获取：原版结构奖励箱 0.25%（每箱最多 1 个）；创造分类或指令
- 用途：与起源魔法绑定；按 i 键选技能，右键释放时间暂停或空间传送。
- 关键数值：拿到即掌握全部起源技能，没有等级、不参加考试。
- 详见：见 §4 魔法体系

### 魔法附加书

- 名称 / ID：魔法附加书（Magic Attachment Book，`magic_attachment_book`）
- 获取：原版结构奖励箱 3%（每箱最多 2 个）；创造分类里 I / II / III 各占一格
- 用途：在魔法附加台给普通武器附加「魔法攻击」。
- 关键数值：I / II / III = 1 / 2 / 3 倍；只对魔法体生效；高等级覆盖低等级，不能叠加。
- 详见：见 §4 魔法体系

### 起源令牌

- 名称 / ID：起源令牌（Origin Token，`origin_token`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：右键单臂举起，展示用；标签写着「起源组织的令牌」。
- 关键数值：没有战斗与功能效果；起源魔法的入口是魔法书。
- 详见：见 §4 魔法体系

### 生命转换令牌

- 名称 / ID：生命转换令牌（Life Conversion Token，`life_conversion_token`）
- 获取：创造分类「沐玖萱」或指令；无配方
- 用途：右键直接打开角色切换界面，选默认 / 有生命的魔法体 / 特殊-icefair。
- 关键数值：能转包括特殊角色在内的全部角色（生命迁移石做不到这一点）。
- 详见：见 §9 生物与角色
