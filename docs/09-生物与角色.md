# §9 生物与角色

## §9.1 没有生命的魔法体

**没有生命的魔法体**（`lifeless_magic_body`）是敌对生物，外观套用玩家模型，生成时尺寸在你默认身高的 0.5~1.5 倍之间随机。

它会**无差别攻击**：在半径 50 格内随机挑目标——动物、怪物、村民、玩家都算。两条边界：**不打同类的魔法体**；**不主动打创造模式与旁观模式的玩家**。**被谁打了就先还击谁**，哪怕对方在创造或旁观也一样。

它不用法杖也能施法，每次随机选模式：点式 45%、单发线式 25%、持续线式 10%、攻击魔法阵 20%。受到攻击时有 25% 概率放出一枚防御魔法阵，挡 3 秒。

它施法同样消耗所在区块的魔力（见 §6.1）。作为魔法体，它只受到魔法伤害：普通武器的物理部分无效，箭、三叉戟、雪球这类物理投射物会直接穿过；本模组的净化魔法球与归零能打中它。

## §9.2 刷新与掉落

刷新不受和平模式限制，除游戏默认不能自然刷怪的地方外，任何维度都会尝试。**每 3 分钟尝试一次**，成败看所在区块的魔力：

- 区块魔力 ≤ 10000：概率 0.1%，刷出一只消耗 3000，个体生命 50。
- 区块魔力 > 10000：概率 5%，刷出一只消耗 5000，个体生命 80。
- 魔力不够 3000 / 5000 就不刷，所以它不会无限堆积。

掉落有经验、魔力与概率水晶：击杀给 20 点经验，并向所在区块释放 800 点魔力；另有 **10%** 概率掉 1 个普通**魔法水晶**，考试 / 试炼里召唤出来的魔法体按 **30%** 算，且这一颗**直接进奖励箱**。两种情况都**不受抢夺加成**。它没有单独的生成上限，靠"3 分钟一次 + 每次消耗 + 魔力缓慢恢复"自然受限。

## §9.3 有生命的魔法体

**有生命的魔法体**是玩家可扮演的角色（角色编号 1，指令字段 `entity magic`），和 §9.1 的生物不是同一个东西：那是生物，这是你扮演的角色。

变身后物理免疫：箭、火球、雪球等投射物直接穿过你，近战与物理伤害也不生效，只有魔法伤害能打中。

仍然生效的伤害：火焰（燃烧、岩浆、营火）、冰冻、溺水、凋零效果，以及 `/kill` 与虚空。

切换途径：`/mugewrayce entity` 指令、柃之册的「角色切换」、生命转换令牌右键；生命迁移石只能在默认与它之间转（见 §10.10）。角色存进存档，退出重进仍在。

## §9.4 特殊-icefair

**特殊-icefair** 属于魔法体，兼具 §9.3 的全部特性，另外自带自动防御阵，尺寸用 icefair 特殊尺寸组。

被近战或投射物（箭、三叉戟、雪球、火球、监守者声波等）命中的瞬间，它会先在你受击方向、贴着身前生成一枚直径 0.5 格的净化魔法防御阵，挡住这一下——首次受击也挡得住，阵维持 3 秒。环境伤害（火焰、冰冻、溺水、凋零、摔落）不触发。

同方向或夹角不超过 60° 的连续攻击会重置这 3 秒；换个角度打，就再长一枚；满 4 枚时四枚竖着围你一圈（每 90° 一枚），任何方向都能挡，整体 3 秒。防御阵挡不住来自魔法阵的伤害。

**只弹原版投射物**：箭、三叉戟、雪球、火球这类原版投射物照旧被弹反；**本模组的净化魔法球不再被弹反**——撞上这枚自动防御阵会被吸收，并把这个阵的 3 秒刷新一次（手动张开的净化防御阵仍是老规则，会反弹投射物，见 §3.9）。

离开 icefair 时尺寸恢复默认，自动防御阵一并清掉。注意它不会让投射物穿过，而是被命中后触发防御。

## §9.5 身高与联动

身高范围 10~1000 厘米，用 `/mugewrayce size` 系列指令或柃之册里的玩家尺寸界面设置；完整子命令见 §11.1，界面操作见 §10.10。

身高不是只改模型：移动速度、跳跃强度、生命值、攻击伤害与击退、交互距离、安全摔落距离、最大行走高度都会按比例联动。

还有一组预设的「特殊尺寸：icefair」，可在界面里点选，或用对应的 size 子命令套用。没有生命的魔法体生成时的 0.5~1.5 倍尺寸，也走这套系统。

身高与联动属性随玩家数据保存，重进游戏不会丢。
