该文件夹用于存放模组介绍册完整文档。

To AI Agent:

- 方便起见，模组介绍册文件上传至本处，通常审阅时直接在本处完成，即与本地的文件相比，本处的文件为最新版本，但是有时可能优先在本地编辑，这需要你判断哪一个是最新的。如果本处（Github）为最新，那么需要将这里的内容同步到本地；如果本地为最新，将本地内容上传至该文件夹。
- 如果有必要，文件的名称、排序和数量可能会修改，这也需要你进行同步，同步规则同上。
- 请不要将无关文件放在这里！
- 关于模组介绍册编写计划草案的使用：
  - 每一个“# abc”为一个文件，其中包括一些当前版本没有但未来会做的内容，需要保留空位，方便后期维护；
  - 每一个“## abc”为文件内的一大章，其中部分已经写好，不需要重写；
  - 每一个“* abc”为备注，标注了这里要写什么内容，这需要你写入具体的内容（不要将备注写进去）；
  - 编写时可以参考https://zh.minecraft.wiki/；
  - 介绍册面向的对象是玩家不是AI或者项目维护者，非必要不要采用太“结构化”的表述方式，不要太死板，请仅包含当前特性，不要写入日志性内容或者其他多余的内容；
  - 暂不分写入模组或wiki，全按写wiki写，写入模组的内容由我亲自选；
  - 除了日志内容外，其他无关wiki但有必要的内容写在这个README文件里面，具体写在下面的横线后面。
