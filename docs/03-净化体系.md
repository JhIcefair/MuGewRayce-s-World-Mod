# §3 净化体系

## §3.1 净化水晶

净化水晶（Equipoise Crystal，`equipoise_crystal`）是净化系的入口。拿在手里，它套用原版铁剑的战斗属性：面板伤害 10、攻速 −2.4。

长按右键持续生效：你身上会挂上一整套增益——力量 X、生命恢复 20、抗性提升 50、抗火、伤害吸收 X、饱和，时长 60 秒，长按期间每 tick 刷新保持。松手后增益不会立刻消失，会继续走完剩余的 60 秒。

长按期间，你脚下会出现一块贴地的净化法阵，边长 2 格，跟着你移动，松手即消失。它只是视觉表现，真正的效果挂在你自己身上（见 §3.9）。

物品身份与获取见 §7 物品图鉴。

## §3.2 净化法杖

净化法杖（Equipoise Staff，`equipoise_staff`）是净化系的施法器：手持右键即施法，**不消耗区块魔力**。它现在共有 **15 种模式**：原来的七种（点式、单发线式、持续线式、普通防御魔法阵，加单体治愈、群体治愈、群体伤害三种魔法阵）保持不变，另加 **8 个自然与闪光技能**（编号 7~14）。

- **点式**：单击发射净化魔法球，**50** 点伤害；长按充能后 **75** 点，命中方块时产生 TNT 规模的爆炸。
- **单发线式**：线段状的高频点式，**65** 点。
- **持续线式**：持续的高频点式，**每刻 10** 点。
- **普通防御魔法阵**：竖立在你视线前方 0.5 格、随视角转动，直径 3 格（随身高缩放）；挡住伤害并反弹投射物，但挡不住魔法阵的伤害，且必须保持长按。

另有单体治愈、群体治愈、群体伤害三种魔法阵，行为见 §3.9。

**新增的 8 个技能**按下右键立即结算（不走蓄力），效果同自然魔法的同名技能（见 §4.5），但净化法杖用它们不扣魔力：**点火**在指定位置或范围点火；**融化**把浮冰 → 冰 → 水、蓝冰 → 浮冰 → 冰 → 水逐级化开；**冻结**让水结冰、冰变浮冰与蓝冰，也能渐渐冻住生物；**制冰**直接造冰；**召雷**召来一道闪电；**生水**生成水源；**前方闪光**在你前一格放一个光源；**指向闪光**在指向位置放同样的光源。

换模式不换物品：按 **i 键**（综合设置按键）打开设置。界面是**三列**——左列 4 个、中列 3 个加一个「确认」、右列 8 个技能；点击选中后点「确认」或按回车生效（**方向键焦点导航尚未实现**，见 §10）。净化系自成一套账：不论哪种模式，都不扣区块魔力，也不参与魔力的扣除、迁移与恢复（见 §6）。

## §3.3 净化圣剑

净化圣剑（Equipoise Sword，`equipoise_sword`）是净化系的近战武器，面板伤害 **2000**、攻速 2.0。

它带剑类标签，所以横扫能正常触发，剑类附魔也照常吃。2000 是面板值——按魔法伤害结算，不吃护甲，只受"保护"附魔与抗性提升减免（口径见 §3.10），所以它面对高生命目标时最省事。

用方向键可以从其它净化物件直接切到它（见 §3.10）。物品身份与获取见 §7 物品图鉴。

## §3.4 净化圣弓

净化圣弓（Equipoise Bow，`equipoise_bow`）完整套用原版弓：耐久 384、可附魔、右键蓄力，蓄得越久打得越远越疼。唯一的不同是**不需要背包里有箭**——空手也能射。

拉弓时有三种状态贴图，对应原版弓的三个蓄力阶段，所以从"刚拉开"到"拉满"你能看出区别。伤害的高低与蓄力程度挂钩，按原版弓的规则走，没有额外数值。

用方向键可从其它净化物件切到它（见 §3.10）。它射出的箭算魔法伤害，不吃护甲。物品身份与获取见 §7 物品图鉴。

## §3.5 归零

归零（Zero Reset，`zero_reset`）是净化系的重火力。手持姿态同原版弓（手臂沿垂直方向抬高 3 像素），右键发射净化魔法球的**归零变体**。

- **单击**立即发射；**按住不放**则连发，间隔 **2 tick**（0.1 秒），是原版弓按住右键射速的两倍。
- 弹道直线、无重力，速度 **4.5 格/tick**，飞行超过 **1024 格**自动消失。
- 命中实体造成 **2000** 点伤害。
- 命中方块则**打破该方块**后消失，不会插在地上；硬度 −1 的方块（如基岩）打不破，并受防爆规则约束（见 §3.10）。

归零排在弓之后，用 → 键切到它（见 §3.10）。物品身份与获取见 §7 物品图鉴。

## §3.6 净化光环

净化光环（Equipoise Halo，`equipoise_halo`）戴在头盔位。它的外观是一层**头戴平面模型**（`display.head`），像头饰一样贴在头上、随视角可见，不再走盔甲贴图层。右键可以直接穿上，或与当前头盔交换。

属性：**+20 护甲、+20 盔甲韧性、+80% 击退抗性**。

自带附魔：水下速掘 I、保护 50、爆炸保护 50、火焰保护 50、弹射物保护 50、水下呼吸 X。

它火焰免疫、不可破坏——戴着它下岩浆也不会烧掉。获取见 §7 物品图鉴。

## §3.7 生命转换令牌

生命转换令牌（Life Conversion Token，`life_conversion_token`）是一件"换身份"的道具：右键直接打开角色切换界面（无背景），不必经过柃之册。

可选角色：默认、有生命的魔法体、特殊-icefair……也就是说，**三者都能转**的就是它。点一下角色立刻切换并关闭界面——没有确认键。

外形与手持样式同起源令牌，是一张平面贴图。

它的定位是"全能版"：生存模式能拿到的生命迁移石只能在默认与有生命的魔法体之间转，转不了特殊角色（见 §3.8）。角色本身的特性与差异见 §9。

## §3.8 生命迁移石

生命迁移石（Life Migration Stone，`life_migration_stone`）是生命转换令牌的"生存版"：刷新在原版结构的奖励箱里，概率 **5%**，每个箱子最多 1 个。

右键打开与令牌类似的界面（无背景）：选目标角色 → 点「确认」→ 执行转换并**消耗这块石头**。

限制很清楚：**只能在"默认 ⇄ 有生命的魔法体"之间转换**，不能转成特殊角色（例如 icefair）。想转特殊角色，只能用生命转换令牌（见 §3.7）。

角色能力差异见 §9，获取见 §7 物品图鉴。

## §3.9 魔法球、法阵与魔法阵

净化系有三个配套实体，它们不是物品，拿不到手上。

- **净化魔法球**：直线飞行、无重力，速度 4.5 格/tick，超过 1024 格消失。它是一颗实体的飞行光球，渲染为始终面向相机的平面贴图，尺寸 **0.25**；**按住右键蓄力时球会悬停在手前**，松手才发射。两个外观变体：法杖变体（点式）与归零变体（归零、单发与持续线式共用）。普通魔法杖的点式球是另一套实体球（`magic_orb` 贴图，球体约 **0.4** 格、蓄力约 **0.5** 格，按类型染色），见 §4.10。
- **净化法阵**：净化水晶长按时出现在脚下，边长 2 格、水平贴地、跟随你，松手消失；半透明 + 自发光（亮度 50%）。
- **净化魔法阵**：由净化法杖长按召唤。单体治愈边长 2 格、跟随你，效果同净化水晶但每个只 3 秒、每 tick 刷新；群体治愈与群体伤害边长 6 格、固定在落点，覆盖半径 3 格加阵上方 5 格，可触及 256 格，群体伤害每秒 **15~50** 点且不伤施法者；防御阵见 §3.2。

**存在时间**：防御阵必须保持长按；其余阵法松手后保留 **30 秒**并继续作用。

**icefair 的自动防御阵**：箭、雪球等原版投射物照旧被弹开；本模组的直线魔法球——点式球、归零球、充能球——撞上它会被**吸收**，不反弹、也不伤害持有者，并刷新这个阵的 **3 秒**计时（见 §4.13）。手动张开的净化防御阵不在此列，仍按 §3.2 的规则反弹投射物。

## §3.10 净化系通用规则

- **切换**：净化五件用方向键互切，不打开任何界面。手持净化水晶时 ↑ 法杖、↓ 圣剑、← 圣弓、→ 归零；手持其中任一件时，按它自己的方向键切回水晶；手持 A 按 B 的方向键直接到 B。键位设置见 §10。
- **五件通用特性**：净化水晶、法杖、圣剑、圣弓、归零都**火焰免疫 + 不可破坏**。
- **伤害归属**：净化系的一切伤害——近战、箭、点式与线式的魔法球、归零、群体伤害魔法阵——都算**魔法伤害**。它不吃护甲，只受"保护"附魔与抗性提升减免。
- **不耗魔力**：净化系不消耗区块魔力，也不参与魔力的扣除、迁移与恢复（见 §6）。
- **破块受防爆约束**：归零破块、点式充能命中方块的爆炸、群体伤害魔法阵等一切破坏方块的效果，在关闭防爆时都不能破坏方块；硬度 −1 的方块（基岩等）任何情况下都不可破坏。
