# 模组概述

## 模组名称

- 中文名称：沐玖芸萱设定集
- 英文名称：MuGewRayce's World

## 模组支持的版本

- 游戏本体：Minecraft 26.1（截至2.1.1）
- JAVA：Java 25
- 模组加载器：Fabric
- 历史支持：26.1（截至2.1.1）

## 简要介绍

模组简称【沐玖芸萱设定集】，全称【沐玖芸萱的世界的设定集】，其中【沐玖芸萱的世界】指的是【莱柯希亚】，模组内容主要是莱柯希亚世界观中的内容和设定。

主要内容包括：

- 独立的魔法体系（起源魔法、净化魔法、自然魔法）
- 魔法的学习和提升
- 特殊角色——魔法体
- 空间维度（将来）

## 背景设定

莱柯希亚是在大世界秩序和世界秩序的作用下由创造女神和破坏女神共同创造一个世界。

在这里，魔法是最强大的一种力量。

莱柯希亚的魔法与其他世界不同，有着一套独立的运行法则，而且不会受到不属于这个世界的大多数力量影响。

魔法并非所有人都掌握，需要经过专门的学习和训练。不过学习魔法不看个人特质，因为释放魔法的本质是操控空气中的魔法粒子，而空气中的魔法粒子几乎用不完（很少出现魔法粒子空洞）。

除了常规的魔法之外，人们还会借助【实体魔法阵】来增强魔法的威力。这需要用方块和魔法水晶搭建专门的实体魔法阵。

作为魔法粒子的聚合体的魔法水晶能向外界释放魔法粒子，所以即使空气中没有可供操控的魔法粒子或者魔法粒子不足，只要随身携带有魔法水晶就能释放魔法。

有一种特殊的魔法水晶叫永恒水晶，它能向外释放无尽的魔法粒子；还有一种特殊的魔法水晶叫不稳定水晶，一旦接触空气就会进入不稳定状态，随时可能爆炸！然而据说世界的核心——起源水晶就是一种不稳定水晶。

据说有一种极其特殊的存在叫魔法体，它不是生物，但外形长的像一个人类，本质上是魔法水晶。传说它没有生命，但是会无差别攻击周围的一切，它会使用魔法，只能受到魔法伤害，几乎免疫一切物理伤害，是一种非常危险的存在。不过形成条件非常苛刻，几乎遇不到（当然主动召唤的就另说了）。

莱柯希亚存在实际上的统治阶级，这是一个起源时期在女神的支持和一部分勇士的推动下成立的一个组织——起源组织。这个组织通常会主动调停各个地区的战乱，维护莱柯希亚的和平与稳定。由于女神的离开，这个组织实质上的统治者换成了净化之子。

# 快速开始

## 入门流程

1. 合成魔法学习讲台；
2. 在魔法学习讲台中获取魔法附加台和魔法聚合台然后选择想学的魔法并申请魔法学习证；
3. 通过魔法聚合台合成魔法水晶（或者通过挖掘魔法水晶块获得魔法水晶）；
4. 在魔法附加台中结合申请的魔法学习证合成魔法杖。

## 基础进阶流程

1. 在魔法学习讲台申请考试或试炼并完成；
2. 在魔法学习讲台升级魔法学习证并选择学习新内容；
3. 在魔法附加台更新魔法杖信息。
