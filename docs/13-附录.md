## §13.2 语言键前缀

语言键是界面文字的取词地址，中文与英文各一份，键名完全一致。前缀决定这段文字**用在哪里**：

| 前缀 | 用在哪 | 形如 |
|---|---|---|
| `item.` | 物品名 | `item.mugewrayce-mod.magic_staff` |
| `block.` | 方块名 | `block.mugewrayce-mod.magic_study_lectern` |
| `entity.` | 实体名 | `entity.mugewrayce-mod.lifeless_magic_body` |
| `container.` | 容器界面标题，按方块 ID 取 | `container.mugewrayce-mod.magic_study_lectern` |
| `gui.` | 界面里的文字：标题、按钮、字段名、红字提示 | `gui.mugewrayce-mod.magic_study_lectern.apply` |
| `tooltip.` | 物品悬停时多出来的说明行 | `tooltip.mugewrayce-mod.magic_staff.bound` |
| `key.` | 按键名，命名空间不带 `-mod` | `key.mugewrayce.settings` |
| `itemGroup.` | 创造模式物品栏里那一栏的标题 | `itemGroup.mugewrayce` |

几条规则：

- 前缀之后固定跟命名空间，再按"界面 / 字段"用点分层；层级越深越具体。
- 同一句话被多个界面用到时只建一个键，别各建一份——比如编号、无效提示是共用的。
- 界面文字一律走 `gui.`，不要塞进 `tooltip.`；`tooltip.` 只管物品悬停的补充行。
- 方块物品用方块名显示，所以它的名称走 `block.`，不是 `item.`。
- 改中文名时只需改中文语言文件；键名不动，英文那份同步改值即可。

- **火 / 冰 / 雷电 / 水**四种类型暂时沿用"普通自然魔法"这一套。
