# §1 模组概览

## §1.1 这是什么

**沐玖萱设定集（MuGewRayce's World）** 是一个 Fabric 模组，模组 ID 为 `mugewrayce-mod`。

它把两套体系装进同一个世界：

- **净化体系**：一套以"净化"为名的武器与道具（水晶、法杖、圣剑、圣弓、归零）。
- **魔法体系**：分类型、分模式、分等级的施法系统，配魔力、学习、考试与试炼。

两套体系都能独立玩；也可以混着用——净化系造成的伤害同样算魔法伤害（见 §3.10）。

几个上手就能感觉到的点：

- **水晶三件套**：水晶块（主世界地下，每区块 5 次尝试、约 20% 出一团）→ 水晶拆合台（8 个普通魔法水晶 ↔ 1 块水晶块）→ **普通魔法水晶**（材料），采集到使用的闭环（见 §8）。
- **净化法杖 15 种模式**：除原来的点式、线式、魔法阵，还含 8 项技能——点火、融化、冻结、制冰、召雷、生水、前方闪光、指向闪光；设置界面按**三列**排（见 §3.2、§10.2）。
- **时间暂停只停区域、昼夜照常**：受影响区域内的一切暂停，昼夜照常推进，玩家本身永不被冻（见 §4.8）。

## §1.2 两条主线之外还有什么

除两套体系，模组还带了这些长期内容：

- **特殊角色**：默认 / 有生命的魔法体 / 特殊-icefair，附带身高与联动属性、`/mugewrayce` 指令（见 §9）。
- **百杉包**：一个便携背包，有生存模式合成表（见 §10.11）。
- **柃之册**：记录与查看用的书册。
- **魔法书**：时间暂停与传送（见 §4.8）。

## §1.3 版本与环境

- 本册对应版本：**2.1.0**（模组 2.0 系列，代号"魔法体系"；W20 已施工，待验收）。
- 运行环境：**Minecraft 26.1** + **Fabric** + **Java 25**。
- 安装方式与普通 Fabric 模组相同：放进 `mods` 文件夹，依赖 Fabric API。
- 升级前请先备份存档——2.0 会迁移旧的存档文件（见 §12.2）。

## §1.4 创造模式分类

模组所有物品都收在一个创造模式分类里：

- 分类名：**沐玖萱**（ID `mugewrayce`）。
- 位置：创造模式物品栏顶部一行的第 7 位。
- 新增物品不会另开分类，继续放进这个分类。
- 顺序：**高级魔法学习讲台**排在**魔法学习讲台**前面。

## §1.5 怎么拿到物品

- **所有物品都能从创造模式物品栏拿到，也能用指令拿到。**
- 但**部分物品直接拿到会无效**：魔法学习证、初学魔法考试申请书、魔法试炼申请书，以及它们的通过证明（魔法熟练证明、魔法试炼晋级认证）。这些物品需要"状态信息"，凭空拿到的那一份用不了（见 §5.2）。
- 生存模式按各自配方获取；创造分类只负责"陈列"，不负责"生存能不能做出来"。
- 高级魔法学习讲台是**例外**：它只存在于创造模式与指令，没有配方（见 §8.2）。
- **水晶拆合台**同样没有原版合成配方，只能用创造分类或 `/give` 拿到；「拆分 / 合成」都在它的界面里做（见 §8）。

## §1.6 与 1.2.7 相比变了什么

如果你玩过 1.2.7，这一版有几处会直接影响手感：

- **键位**：原来的 i 键改成"综合设置按键"（法杖模式、水晶、魔法书、角色、尺寸等设置都用它）；净化系五件的切换**改用方向键**（见 §2.3）。
- **净化法杖模式变多**：除原来的点式，还有普通防御魔法阵、单发线式、持续线式，外加 8 项技能，共 **15 种**（见 §3.2）。
- **净化长枪删除**：物品、贴图、模型、语言键、切换条目一并移除；旧存档里的长枪不用管。
- **角色改名**："魔法体"→"**有生命的魔法体**"，角色编号与指令字段不变。
- **伤害归属**：净化系的全部伤害统一算**魔法伤害**。
- **生命转换令牌**：去掉了"火焰免疫"与"不可破坏"两条特性，其余不变。
- **百杉包**：新增生存模式合成表（线—地毯—线 / 地毯—箱子—地毯 / 线—地毯—线）。
- **存档位置**：统一放到 `data/mugewrayce-mod/` 下，并会自动迁移旧文件（见 §12）。

## §1.7 本册怎么读

本册按"玩家会怎么用"分章，每一类只写自己的内容：机制在机制章讲一次，物品与界面章只写"它是什么、怎么用"，细节用 `见 §x.y` 指过去。

三条常用路径：

- **第一次玩**：§2 新手入门 → §3 净化体系 → §4 魔法体系 → §5 学习与进阶。
- **要查某件东西**：§7 物品图鉴 → §8 方块与设施 → §10 界面与操作。
- **要开服 / 排错**：§11 指令与多人 → §12 存档与排错。

> 注意：本册的 § 编号是册内编号，与规格文档的 § 编号无关。
